# ChatGPT 这条路怎么走

先把话说清：这条路是半自动。

选题、写稿、备素材、拟验收，这些 ChatGPT 都能帮你干。做片的脚本要在你本机跑。最后发布这一步，它备好待发包，你自己打开小红书发。

它没有跟 Muse 等价的常驻定时，也没有稳定的子 agent 编排。所以别指望它每天早上自己开工、自己发完。

## 装法

1. 建一个项目，把仓库里的 `core/`、`orchestration/`、`pipeline/`、`motion-lib/` 放进项目文件，或者在对话里指给它读。
2. 把 `project-instructions.md` 的内容粘到项目指令里。那是一份短稿，只放核心口径，完整的规矩还是以 `core/` 为准。
3. 按根目录的设置向导填好配置，在对话开头把配置贴给它，或者放进项目文件。
4. 登录不用经过它。小红书登录是你本人在 App 或网页上扫码，跟这条路无关。

## 一天怎么跑

1. 你说一句「跑今天的日更」。
2. 它按 `core/CONSTITUTION.md` 和阶段手册，先选题、再写稿，每步的产出落成文件给你。
3. 做片：它按 `pipeline/` 的流水线给你拼页面和脚本，你在本机跑捕获和合成。跑完把成片和 `validate.py` 的输出贴回来给它验。
4. 验收过了，它把待发包整理好发你。
5. 你照着待发包里的发布清单，自己在小红书发出去。
6. 发完把链接和实际发布时间告诉它，它帮你补台账、拟第一条评论之后的跟进话术。

全程一个对话顺着做，没有子 agent 分工。阶段之间不要跳：稿没定，不要做片。

## 定时怎么办

没有常驻定时，就靠手动：

- 日更：每天你喊一次。
- 看门狗：没有。你发完自己看一眼台账，确认今天这条记上了。
- 发后跟进：发布后头 2 小时，你自己在 App 里看评论。有要回的，把评论贴回来，它帮你拟，你贴回去发。
- 周复盘：周末你喊一次，把本周台账贴给它，按复盘模板走一遍，它给出教训册和 `core/` 的修改稿，你确认后再落文件。

觉得手动太累，就是换 Muse 那条路的信号。这句话不藏着。

## 待发包

固定四个文件，和另外两家同一份格式：

- `video.mp4`：验收通过的成片
- `cover.jpg`：单独做的封面
- `post.md`：标题、正文、话题、第一条评论
- `publish-checklist.md`：照着勾的发布清单，模板在 `orchestration/publish-checklist.template.md`

发的时候注意清单里两条：话题要一个一个点到变蓝，蓝数对不上就停；内容声明要选 AI 合成那一项。

# 常见问题

## 要花钱吗？

工具这条线不花钱：GSAP、ffmpeg、Playwright、免费配音，都是免费的。但 agent 平台本身要不要钱，看你用哪家、什么套餐，那笔账不在这个仓库里。还有一笔是时间：网页做片一帧一帧截，一条片的渲染要等不少分钟。

## 不会代码行不行？

不用你写代码，哪条路都一样。装环境、建定时，要照着向导敲几条命令，向导写到了能照抄的程度。脚本跑不通，把报错原话贴回给助手，它会告诉你下一步。再不行，就用 `orchestration/scheduling/manual-checklist.zh-CN.md`，纯手动跑，慢但能跑。

## 号会不会封？

没人能保证不会。平台对 AI 托管有明确治理，全自动代发代互动是风险最高的那一档。怕封就走半自动：备好待发包，你自己看一眼、自己点发布。细节看 `compliance.zh-CN.md`。

## 三家选哪家？

三家都是云端 agent，差别在批准规则和你能不能用上。想全自动、又要现成跑通的，选 Muse，已经有号在日更用。手里有 ChatGPT Pro 或 Business Premium，可以试 Dots：能力跟 Muse 对齐，但我们没实测过，发布先在它的规则里设成要批准。Grok Bot 还在 beta，只开放给部分 SuperGrok Heavy 用户，发布前默认会停住等批准，同样没实测过。详表在 `capability-matrix.zh-CN.md`。

## 视频为什么用网页做？

因为 agent 写 HTML 最顺手。版面用 CSS 排，动画用 GSAP，组件攒在 `motion-lib/` 里反复用，改一处文案不用重剪整条片。代价是渲染靠逐帧截图，慢。想要快，就得换工具链，这套流程不提供。

## 能不能换个品类，不做科技？

能。规矩里跟品类绑定的只有三处：配置里的品类清单、信源清单、选题手册里举的例子。把这三处换成你的领域，剩下的流程——写稿标准、做片、验收、发布过闸——原样能用。敏感词附册是按平台规则写的，换品类也建议留着。

## 一定要每天发吗？

不用。频率在配置里，改成一周三条也行。日更那套时刻只是推荐值。发得少，看门狗和跟进照样能用，把触发时间对上你的发布节奏就行。

## 发不出去、话题点不蓝怎么办？

先停，别硬发。话题点不蓝是发布闸口，不许删话题裸发。把待发包存好，按清单从主站重新进一次创作者平台再试，最多两次。还不行就人工在 App 里发，待发包里的东西一样不少。报错怎么写进汇报，看 `orchestration/orchestrator.zh-CN.md` 的四要素。
